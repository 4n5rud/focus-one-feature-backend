# 자동 코드 리뷰 봇 어댑터 (예시: CodeRabbit) — 선택

[code-review-isolation.md](../rules/code-review-isolation.md)가 정의하는 9단계 자체 점검을
**대체하는 게 아니라 보완하는** 선택 훅이다. 자체 점검은 컨텍스트가 격리된 에이전트가 diff를
한 번 보는 것이고, 리뷰 봇은 PR이 열린 뒤 CI에서 자동으로 한 번 더 보는 것이다 — 두 겹을
다 쓸지, 자체 점검만으로 충분한지는 팀이 정한다.

## 예시: CodeRabbit
- PR을 열면 자동으로 diff를 리뷰하고 코멘트를 남긴다.
- 무료 플랜은 계정 단위로 리뷰 횟수가 제한된다 — push할 때마다 자동 실행되게(예:
  `auto_incremental_review`) 두면 초안을 다듬는 단계에서 리뷰 횟수를 금방 소진할 수 있다.
  PR을 draft에서 ready로 전환할 때만, 또는 특정 라벨이 붙었을 때만 실행되도록
  `.coderabbit.yaml`에서 트리거를 좁히는 걸 권장한다.

## 이 훅을 다른 도구로 교체할 때
Greptile, Graphite, 사내 정적 분석 봇 등 어떤 도구를 쓰든 핵심은 같다 — "PR이 열리면 사람
리뷰 전에 자동으로 한 번 더 본다"는 보완 단계라는 점, 그리고 무료/저비용 플랜일수록 트리거
조건(언제 실행할지)을 좁혀서 할당량을 아껴야 한다는 점이다.
