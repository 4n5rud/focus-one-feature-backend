# assets

Drop repo screenshots/media here — the root `README.md` (Korean, primary) / `README.en.md`
already point at
these filenames, so adding a file with the right name makes it show up with no other
edits needed:

- `screenshot.png` — a single screenshot (e.g. an approval-gate prompt in the terminal).
- `demo.gif` — a short, silent, looping demo (a few key moments, not a full walkthrough).
  GIFs are what actually autoplay inline in GitHub's README renderer — an mp4 embedded
  the same way will not.
- `thumbnail.png` — a static frame used as a clickable thumbnail if you link out to a
  longer video (YouTube, etc.) instead of a GIF.

For a longer usage video, see the "Screenshot & demo" section in the root README for the
two supported options (GitHub-hosted video vs. a YouTube thumbnail link).
